# StudyBuddy AI 🎓

StudyBuddy is an all-in-one intelligent learning assistant that combines **Machine Learning** and **Generative AI** to help students track performance and improve their skills.

## 🚀 Features
- **AI Mentor Chat:** Powered by Google Gemini, providing instant academic guidance.
- **Grade Predictor:** Uses a **Random Forest Regressor** to estimate student performance based on attendance and study habits.
- **Writing Lab:** Analyzes uploaded handwriting images to provide feedback on spacing and letter formation.
- **Modern UI:** Built with Flask and Tailwind CSS for a premium, dark-mode experience.

## 🛠️ Tech Stack
- **Backend:** Python (Flask)
- **AI/ML:** Google Generative AI (Gemini 1.5), Scikit-Learn, Pandas
- **Frontend:** HTML5, Tailwind CSS, JavaScript
